# Real Estate Price Prediction
This is a Linear Regression Model implemented in Google Colab.

This project predicts real estate prices using Linear Regression based on features from a dataset Real_estate.csv.

## Dataset
- Real_estate.csv contains historical real estate data with features such as:
- Location, Size, Number of Rooms, Age of Property, etc.
- The target variable is the property price.

## Features
- Data preprocessing: handling missing values, feature scaling (if needed).
- Linear Regression model to predict property prices.
- Model evaluation using metrics like RMSE, MAE, and R² score.

## Results
- Provides insights into property pricing based on input features.
- Model performance can be improved with feature engineering or advanced regression techniques.
